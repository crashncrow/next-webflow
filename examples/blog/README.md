# next-webflow example: blog

A Next.js 16 blog whose content lives in the Webflow CMS, using every part of [next-webflow](../../packages/next-webflow):

| File                                                  | Shows                                                                                                                                                                       |
| ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `lib/posts.ts`                                        | Typed reads: `getItems` with `include` (authors), sorting and filters, `getItemBySlug`                                                                                      |
| `components/post-list.tsx`                            | The list, with `WebflowImage`, Option and Switch badges; used by `/`, `/featured`, `/category/[id]`                                                                         |
| `app/category/[id]/page.tsx`, `app/featured/page.tsx` | Filtering by an Option (`category`) and a Switch (`featured`), applied by Webflow                                                                                           |
| `app/posts/[slug]/page.tsx`                           | Every field type: Rich Text with an override, gallery, video, links, email, phone, file, color                                                                              |
| `components/post-video.tsx`                           | A player built from a Video link field's URL (YouTube, Vimeo, video files)                                                                                                  |
| `app/api/webflow/route.ts`                            | The webhook endpoint that refreshes pages when you publish                                                                                                                  |
| `app/api/webflow/draft/route.ts`                      | Signed draft previews (`createDraftHandler`)                                                                                                                                |
| `app/drafts/page.tsx` + `proxy.ts`                    | A password-protected page listing drafts with preview links                                                                                                                 |
| `lib/demo-previews.ts` + `app/api/preview/route.ts`   | **Demo only**, off by default: with `DEMO_PUBLIC_PREVIEWS=true`, posts with unpublished changes show a "Try draft preview" button anyone can use (signed link + draft mode) |
| `app/layout.tsx`                                      | `DraftModeBanner`, light/dark theme                                                                                                                                         |
| `app/globals.css`                                     | Tailwind CSS 4, plus commented styles for Webflow's Rich Text classes (alignment, figures)                                                                                  |
| `webflow/`                                            | Generated by `next-webflow typegen` (`schema.ts`) and yours to edit (`index.ts`)                                                                                            |

## Your Webflow site

The example reads two collections:

- **`posts`**: Name, Slug, `body` (Rich text, required), `main-image` (Image), `gallery` (Multi-image), `video` (Video link), `website` (Link), `contact-email` (Email), `phone` (Phone), `reading-time` (Number), `publish-date` (Date/Time), `featured` (Switch), `accent-color` (Color), `attachment` (File), `category` (Option), `author` (Reference → authors), `co-authors` (Multi-reference → authors). Every field except Name, Slug and Body is optional.
- **`authors`**: Name, Slug.

The committed `webflow/schema.ts` comes from our test site, which also has a collection the example doesn't use (`load-test`). Point it at your site by rerunning typegen; nothing else in the code names a site, collection ID or option.

## Run it

```bash
cp .env.example .env.local   # then fill it in
pnpm install                 # from the repository root
pnpm --filter next-webflow build
pnpm typegen                 # regenerates webflow/schema.ts from your site
pnpm dev
```

To refresh pages on publish, deploy the app and register the webhooks once (they need a public HTTPS URL):

```bash
npx next-webflow webhooks register --url https://<your-app>/api/webflow --token-env WEBFLOW_ADMIN_TOKEN
```

The live demo also sets `DEMO_PUBLIC_PREVIEWS=true`, because its CMS holds only demonstration content: every visitor can then preview drafts. Leave it unset on a real site.

Editors open `/drafts` (HTTP Basic auth, any user name, password `DRAFTS_PASSWORD`) and follow a link to preview a draft.
